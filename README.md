# Digital Loan Application Process Improvement
**A Business Analyst portfolio project** | SQL, Python, Process Mapping, Requirements, Wireframing

> **Data note:** This project uses a **simulated dataset** of 12,000 loan applications (Jan-Dec 2025) generated by `python/generate_data.py`. It is not real bank data. Findings are illustrative and projected impacts are assumption-based estimates.

## Business problem
A retail bank's digital loan journey loses **37.1%** of applicants before a decision, and the average time to decision is **10.8 days**. The project finds out where and why applicants drop off, and defines the requirements for a better process.

## Key findings
| Finding | Evidence |
|---|---|
| Document upload is the biggest drop-off point | 41.4% of all abandonments (1,842 of 4,454), about Rs 2,812M in loan value |
| Incomplete documents hurt badly | 50.3% abandonment vs 30.6%; 14.5 vs 9.5 days to decision |
| Digital channels struggle with documents | Complete first time: Branch 85.6%, Online 60.7%, Mobile 51.1% |
| Mobile app has the highest abandonment | Mobile 42.1%, Online 39.0%, Branch 31.4% |
| Manual verification slows non-salaried applicants | 12.6 days (self-employed) vs 9.6 days (salaried) |
| Long verification waits increase drop-off | 9.0% (1-4 days) to 15.2% (8+ days) |

## Recommendation
Guided document upload with real-time validation, automated e-KYC / income verification, a status tracker with notifications, and save-and-resume. Base case (recover 30% of document-stage abandonments): about **+423 approved loans**, approval rate **54.0% to 57.5%**, about **Rs 577M** extra approved value (assumption-based projection).

## How to run
```bash
pip install pandas numpy matplotlib      # Graphviz needed only for process maps
cd python
python generate_data.py      # creates data/loan_applications.csv
python run_sql.py            # runs SQL queries, saves result CSVs
python build_dashboard.py    # dashboard.png + scenario_projection.csv
python build_process_maps.py # AS-IS / TO-BE PNGs (needs Graphviz)
python build_wireframes.py   # wireframes.png
```
